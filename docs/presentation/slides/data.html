The table rejects bad rows

  • name is unique and not empty
  • type is generic, abb or btc
  • power and price are above 0
  • session fee is 0 or more
  • taper threshold is 0 to 100
  • taper factor is above 0, at most 1

EV Charger Simulation

Page

Charger models are rows in one table called chargers. The database itself enforces the rules, even if another tool writes the rows. The rest of the program only knows the ChargerRepository interface. A factory reads one row and builds the matching charger class. A price changed in the database affects chargers built afterward, not ones already running.
