Wrap-up

Decisions, limits and next steps

Decisions

  • Rules in code, models in the database
  • Storage behind an interface
  • A charge never bills above its hold
  • GoogleTest for parameters and mocks

Limits

  • Specs are read once per charger
  • ABB taper is decided per call
  • No retry if capture fails
  • App has no live feed
  • Rules live in both C++ and SQL

Next

  • A service with an API
  • Retry failed captures
  • A time-stepped charge curve
  • Branch protection on main
