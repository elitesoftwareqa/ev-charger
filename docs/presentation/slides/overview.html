EV Charger Simulation

Page

This is a C++20 simulation of an EV charging session. Charger models come from a SQLite database. Delivery is a CMake build, a Docker image and GitHub Actions. The ABB and BTC specs, the payment terminal and all numbers are made up for the simulation.
