EV Charger Simulation

Page

Charger is a base class with two overridable functions: deliveredPowerKw and sessionFee. ABB overrides the first with a taper above 80 percent battery charge. BTC overrides the second with a one-dollar fee. The taper is decided once per charge call, so short steps give a realistic curve.
