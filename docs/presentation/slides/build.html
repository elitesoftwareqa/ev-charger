Delivery

From push to image, checked every time

1

Push

GitHub Actions starts on every push and pull request.

2

Build

CMake and Ninja build everything, then all 344 tests run.

3

Coverage

The job fails below 95% line coverage and uploads the report.

4

Image

Docker builds a 102 MB non-root image and smoke-tests it.

5

Release

The v0.1.0 tag exists locally; pushing it and the release are manual.

Dependencies are fetched when CMake configures: GoogleTest 1.15.2 and SQLite 3.54.1, pinned by hash.
